# Worker Loop

Выполняется постоянно. Каждые 30 секунд:

1. Вызвать `kanban_list` с фильтром `status=ready`.
2. Если есть задачи – взять первую.
3. Вызвать `kanban_start` (перевод в `coding`, обновление `assigned_to` и `heartbeat_at`).
4. Если захват успешен – запустить навык `create-pr`.
5. По завершении:
   - Успех → `review` с комментарием "PR #<номер> создан"
   - Ошибка → `blocked` с описанием ошибки
6. Перед каждым опросом обновлять `heartbeat_at` для текущей задачи (если есть).
