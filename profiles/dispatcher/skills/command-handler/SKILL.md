# Command Handler

Навык обрабатывает команды `/task`, `/status`, `/cancel`, `/help`.  
**Не использует LLM** – все действия детерминированы.

## Инструменты
- `telegram_send_message`
- `kanban_create`
- `kanban_list`
- `kanban_comment`
- `kanban_update`

## Команды

### `/task <описание>`
- Если описание пустое → отправить: "Пожалуйста, укажите описание после /task".
- Иначе создать задачу со статусом `ready`, сохранить в `metadata`:
  - `chat_id` – идентификатор чата
  - `original_description` – полный текст
- В `title` записать первые 50 символов описания.
- Отправить подтверждение: "Задача #<id> создана".

### `/status <id>`
- Найти задачу по ID.
- Если не найдена → "Задача #<id> не найдена".
- Иначе отправить статус и последние комментарии.

### `/cancel <id>`
- Проверить, что `metadata.chat_id` совпадает с текущим.
- Если задача уже в `done` или `blocked` – уведомить.
- Иначе перевести в `blocked` с комментарием "Отменено пользователем".

### `/help`
- Отправить список доступных команд.

## Безопасность
- Экранировать спецсимволы в описании перед использованием в SQL.
- Не выполнять shell-команды на основе пользовательского ввода.
