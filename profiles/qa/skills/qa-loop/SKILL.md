# QA Loop

Выполняется постоянно. Каждые 30 секунд:

1. Вызвать `kanban_list` с фильтром `status=review`.
2. Взять первую задачу, вызвать `kanban_start` (перевод в `qa`).
3. Запустить навык `review-and-deploy`.
4. По завершении:
   - Успех → `done`
   - Ошибка CI или конфликт → `ready` с комментарием
   - Ошибка деплоя, таймаут, превышение циклов → `blocked`
5. Обновлять `heartbeat_at` перед каждым опросом.
