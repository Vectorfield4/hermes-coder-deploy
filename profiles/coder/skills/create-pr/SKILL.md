# Create PR

Выполняется для захваченной задачи.

## Шаги

1. **Анализ репозитория**  
   - Клонировать/обновить `/workspace/<repo-name>`.
   - Прочитать структуру, выявить технологии (package.json, requirements.txt и т.д.).
   - Учесть `SOUL.md` и `AGENTS.md` (политики разработки).

2. **План изменений** – определить, какие файлы создать/изменить.

3. **Генерация кода** – сгенерировать код через LLM, следуя политикам.

4. **Локальная валидация** (по приоритету):
   - `validation_commands` из `config.yaml`
   - `metadata.validation_commands`
   - если нет – пропустить с предупреждением

5. **Commit и push**  
   - Ветка `feature/hermes-<task_id>`
   - Коммит с сообщением "Task #<id>: <краткое описание>"
   - Push

6. **Создание PR** – через `gh pr create`, получить номер PR.

7. **Завершение** – добавить комментарий с номером PR, перевести задачу в `review`.
